# Dados

Dataset: SMS Spam Collection, disponibilizado pelo UCI Machine Learning Repository.

Página oficial: https://archive.ics.uci.edu/dataset/228/sms+spam+collection

O script `train.py` baixa automaticamente o arquivo oficial para esta pasta na primeira execução. A base contém mensagens SMS rotuladas como `ham` (legítima) ou `spam` (indesejada).

Autores: Tiago Almeida e José Hidalgo (2011).
Licença informada pela UCI: Creative Commons Attribution 4.0 International (CC BY 4.0).
Atribuição: Almeida, T. & Hidalgo, J. (2011). SMS Spam Collection [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CC84.
